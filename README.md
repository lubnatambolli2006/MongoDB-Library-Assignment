# MongoDB Fundamentals Assignment

## Library Management System

This project demonstrates the basic concepts of MongoDB using a Library Management System.

## Database

LibraryDB

## Collections

- books
- authors
- genres

## CRUD Operations

- Create
- Read
- Update
- Delete

## Project Description

The Library Management System stores information about books, authors and genres using MongoDB. It demonstrates how a NoSQL database can be used to store, retrieve, update and delete data.

## Searching

Books can be searched based on different criteria such as author, genre, year and price.

## Conclusion

This project provides practical experience with MongoDB databases, collections, documents and CRUD operations.
